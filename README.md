## 🎮 01 · Silent Reckoning · 1987（静默行动·1987）

**回合制战术战棋** ｜ 1980 年代冷战热战假想 ｜ Godot 4.7.1 ｜ 单人 PVE ｜ v1.0.0 可玩

> 你攻击的不是眼前的敌人，而是你判断敌人 30 秒后、在电磁迷雾中即将出现的坐标。

玩家扮演技术劣势下的**华约（苏联红军）防御指挥官**，在东欧本土以地形熟悉、指挥贷款和坐标预判，抵抗北约（美国联军）的数字化攻势。每回合 60 秒计划、30 秒沙盘演绎，双方命令同时结算；胜负来自对敌人未来坐标的判断，而非操作速度。

- **核心机制**：电磁频谱对抗 · 坐标预判 · 指挥贷款 · 士气系统 · 兵种卡牌
- **内容规模**：10 关战役 · 4 种结局 · 3 幕结构 · 6 名主要人物
- **技术实现**：Godot 4.7.1 / GDScript · 473 项自动化测试断言 · Python 程序化音效合成
