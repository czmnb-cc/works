## 项目简介

玩家扮演**技术劣势下的华约（苏联红军）防御指挥官**，在东欧本土以地形熟悉、指挥贷款和坐标预判，抵抗北约（美国联军）的数字化攻势。

每一回合都围绕**电磁频谱控制**展开：华约推高全频带阻塞干扰，把战争拉回地图、坐标与人力判断；北约争抢高技术窗口，试图在电磁风暴吞没战场前完成速胜。

## 核心玩法

| 机制 | 说明 |
| --- | --- |
| **60 秒计划 / 30 秒演绎** | 双方同时规划、同时结算。胜负来自对敌人未来坐标的判断，而非操作速度 |
| **电磁频谱对抗** | 0%–100% 干扰强度条逐回合改变双方的情报、命中、通信延迟与士气 |
| **指挥贷款** | 可透支未来回合的指挥点，换取当前防线稳固或反击窗口 |
| **不完全情报** | 只能看到确认目标与“最后已知位置”，误差圈、校射与侦察决定你打到哪里 |
| **士气系统** | 伤亡、失联与干扰强度影响部队表现，并通过叙事反馈体现 |
| **兵种与卡牌** | 双方各 3 名司令、7 类兵种、6 张专属技能卡牌 |

## 非对称设计

| 维度 | 华约（玩家） | 北约（敌方） |
| --- | --- | --- |
| 情报 | 初始自带 +1 格坐标模糊，需校射确认 | 确认目标概率 +20%，误差圈小 50% |
| 地形 | 东欧本土：移动消耗 −10%，森林沼泽不减速 | 战场陌生：移动消耗 +10%，树林泥泞减速 |
| 指挥贷款 | 上限 42 点，偿还比 1:1.1 | 上限 30 点，偿还比 1:1.3 |
| 每回合额度 | 14 点（稳定） | 10 点（链路复杂） |
| 频谱 | 专属“洪水”干扰增强 30%，自身副作用减半 | 干扰 >60% 时命中额外 −15%、通信延迟 +1 回合 |

> 设计意图：**技术劣势的一方靠主场、经验与人命换时间；技术优势的一方越先进，在电磁风暴中崩溃得越彻底。**
